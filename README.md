# ROS 2 TurtleSim Workshop Package (Oct 2024)

The package from my first ROS 2 workshop (October 2024): publisher/subscriber nodes and TurtleSim control (move, reset, a small task), plus the `.bashrc` lines participants used.

Files: `py_pkg/py_pkg/` — `num_publisher.py`, `num_subscriber.py`, `move_turtle.py`, `reset_turtle.py`, `task.py` · `ros2_workshop_bashrc.txt`

The maintained version of this material is [Mastering the Basics of ROS 2 with TurtleSim](https://github.com/MechaMind-Labs/ros2-basics-with-turtlesim) in the MechaMind Labs organization.
